# Unused can artwork

Nothing in this folder is referenced by the site. It is kept rather
than deleted because both files are real artwork and the reason each
is here is a question for the business, not a decision the code can
make.

`public/images/ciders/` itself holds exactly one file per cider,
named for that cider's slug. These two had no slug to belong to.

## legendary-dry-previous-label.png

The black-and-teal Legendary Dry label, superseded by the navy 2025
artwork that is now `../legendary-dry.png`.

Worth knowing: **every photograph in
`public/images/cider-details-images/` still shows this older label** —
not just Legendary Dry's own three. So on a detail page the cutout can
and the photographs beneath it are two different labels. Replacing the
photography is the real fix; until then this file is the only record
in the repo of what the cans in those shots actually look like.

## berry-perry.png

A finished can — "Berry Perry", 16 fl oz, 6.8% ABV — with no record in
`data/ciders.ts` and no page on stormalong.com. Either it is
discontinued, or it is missing from the data. If it is still sold it
needs a record; if not, it belongs in an archive rather than in
`public/`.
